SubPath

GitLab allows for Subgroups under a Group, and Subgroups in those Subgroups. To account for this, all subgroups and the actual project slug are in this value; the project slug being the last value delimited by a / or the whole value if there are no slashes. The top-most group is in Owner.

If you are using Owner + SubPath or Identifier in HTTP requests to GitLab, ensure you URL encode them first. ApiIdentifier has been provided for this reason, as a convenience.
