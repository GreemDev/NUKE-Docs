Remarks

This is a CLI wrapper with fluent API that allows to modify the following arguments:

  • <task> via Task
  • --build-cache via BuildCache
  • --configuration-cache via ConfigurationCache
  • --configure-on-demand via ConfigureOnDemand
  • --console via Console
  • --console-unicode via ConsoleUnicode
  • --continue via ContinueOnTaskFailure
  • --daemon via Daemon
  • --debug via DebugLogging
  • --dry-run via DryRun
  • --exclude-task via ExcludedTasks
  • --foreground via ForegroundDaemon
  • --gradle-user-home via GradleUserHome
  • --include-build via IncludeBuild
  • --info via InfoLogging
  • --init-script via InitScript
  • --isolated-projects via IsolatedProjects
  • --max-workers via MaxWorkers
  • --no-build-cache via NoBuildCache
  • --no-configuration-cache via NoConfigurationCache
  • --no-configure-on-demand via NoConfigureOnDemand
  • --no-continue via NoContinueOnTaskFailure
  • --no-daemon via NoDaemon
  • --no-isolated-projects via NoIsolatedProjects
  • --no-parallel via NoParallel
  • --no-rebuild via NoRebuildDependencies
  • --no-watch-fs via NoWatchFileSystem
  • --non-interactive via NonInteractive
  • --offline via Offline
  • --parallel via Parallel
  • --priority via Priority
  • --project-cache-dir via ProjectCacheDir
  • --project-dir via ProjectDir
  • --project-prop via ProjectProperties
  • --quiet via MinimalLogging
  • --refresh-dependencies via RefreshDependencies
  • --rerun-tasks via RerunTasks
  • --stop via StopDaemon
  • --system-prop via SystemProperties
  • --warn via WarnLogging
  • --warn via Stacktrace
  • --warn via FullStacktrace
  • --watch-fs via WatchFileSystem
