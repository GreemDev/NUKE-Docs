Remarks

This is a CLI wrapper with fluent API that allows to modify the following arguments:

  • --additional-data via AdditionalData
  • --backing-store via BackingStore
  • --class-name via ClassName
  • --clean-output via CleanOutput
  • --clear-cache via ClearCache
  • --deserializer via DeserializerClasses
  • --disable-ssl-validation via DisableSslValidation
  • --exclude-backward-compatible via ExcludeBackwardsCompatible
  • --exclude-path via ExcludePaths
  • --include-path via IncludePaths
  • --language via TargetLanguage
  • --log-level via LogLevel
  • --namespace-name via NamespaceName
  • --openapi via OpenApiDescription
  • --output via OutputPath
  • --serializer via SerializerClasses
  • --structured-mime-types via StructuredMimeTypes
  • --type-access-modifier via TypeAccessModifier
  • --version via Version

DisableExcludeBackwardsCompatible<T>(T)

Whether to exclude the code generated only for backward compatibility reasons or not. Defaults to false.

To maintain compatibility with applications that depends on generated clients, Kiota emits extra code marked as obsolete. New clients don't need this extra backward compatible code. The code marked as obsolete will be removed in the next major version of Kiota. Use this option to omit emitting the backward compatible code when generating a new client, or when the application using the existing client being refreshed doesn't depend on backward compatible code.
