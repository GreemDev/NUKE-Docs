Remarks

This is a CLI wrapper with fluent API that allows to modify the following arguments:

  • --clear-cache via ClearCache
  • --dependency-type via DependencyTypes
  • --json via Json
  • --language via TargetLanguage
  • --log-level via LogLevel
  • --openapi via OpenApiDescription
  • --search-key via SearchKey
  • --version via Version

Properties

ClearCache

Clears the currently cached file for the command. Defaults to false.

Cached files are stored under '%TEMP%/kiota/cache' and valid for one (1) hour after the initial download. Kiota caches API descriptions during generation and static index files during search.

public bool? ClearCache { get; }

Property Value

bool?

DependencyTypes

The type of dependencies to display when used in combination with the language option. Does not impact the json output. Default empty.

public IReadOnlyList<KiotaDependencyType> DependencyTypes { get; }

Property Value

IReadOnlyList<KiotaDependencyType>

Json

public bool? Json { get; }

LogLevel

The log level to use when logging events to the main output. Defaults to warning.

public KiotaLogLevel LogLevel { get; }

OpenApiDescription

The location of the OpenAPI description in JSON or YAML format to use to generate the SDK. Accepts a URL or a local path.

public string OpenApiDescription { get; }

Property Value

string

SearchKey

The search key to use to fetch the Open API description. This parameter can be used in combination with the version option. Shouldn't be used in combination with the --openapi option. Default empty.

public string SearchKey { get; }
