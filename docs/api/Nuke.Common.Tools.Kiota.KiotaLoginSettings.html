Remarks

This is a CLI wrapper with fluent API that allows to modify the following arguments:

  • <loginMethod> via LoginMethod
  • --log-level via LogLevel
  • --pat via AccessToken

Properties

AccessToken

You can use either a classic personal access token (PAT) or a granular PAT. A classic PAT needs the repo permission and to be granted access to the target organizations. A granular PAT needs a read-only permission for the contents scope under the repository category and they need to be consented for all private repositories or selected private repositories.
