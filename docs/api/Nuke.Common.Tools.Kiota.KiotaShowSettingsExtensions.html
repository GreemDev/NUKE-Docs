Remarks

This is a CLI wrapper with fluent API that allows to modify the following arguments:

  • --clean-output via CleanOutput
  • --clear-cache via ClearCache
  • --disable-ssl-validation via DisableSslValidation
  • --exclude-path via ExcludePaths
  • --include-path via IncludePaths
  • --log-level via LogLevel
  • --max-depth via MaxDepth
  • --openapi via OpenApiDescription
  • --output via OutputPath
  • --search-key via SearchKey
  • --version via Version

A glob pattern to exclude paths from generation. Accepts multiple values. If this parameter is absent, everything is included.

You can also filter specific HTTP methods by appending #METHOD to the pattern, replacing METHOD with the HTTP method to filter. For example, /users/#GET.
